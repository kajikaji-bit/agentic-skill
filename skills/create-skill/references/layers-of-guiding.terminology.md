## 用語

Layers of Guiding

### 行動を導くものの抽象度（`layers-of-guiding.terminology.md`）

- Layers of Guiding: 考え方から具体的な行動や事例まで、行動を導くものを抽象度に沿って捉える枠組み。
- 信念: 強く抱いている確信。ルールを守る理由になる。
- ロール: スキルを実行するときにエージェントが担う役割。行動原理を持つ。
- 行動原理: 作り手が成果物を作るときに保つ姿勢。信念にあたり、ルールが具体的な行動様式に落とし込む元になる。
- 概念: ルールの背景にある、なぜそうするかの主張を、対象を理解するための言葉として括り取ったもの。
- ルール: ある範囲で適用される判断ロジックとして、領域で先に合意しておく取り決め。原則・規約・規律と、個別の禁止・許可・制約を含む。合意しておくことで成果物の統一感を保ち、作るときの摩擦を減らす。テンプレートから発見でき、抽象化すると背景にある概念や行動原理が見えてくる。
- スキル: 成果物に至る手順と、手順が使う用語集・テンプレート・事例・チェックリスト・レビュー項目を一つのディレクトリに持つ手順書。テンプレートだけでは分からない作成過程を補い、ワークフローの各工程で何をするかを示す。
- 規範の階層: 行動を導く規範を抽象度の連続体に並べて段に切り、隣り合う段だけを導出と検証で結んだもの。
- 段階的な一般化: 事例から原則と例、そこからテンプレートと用語集、そこからルール、ルールから概念と行動原理へと、一段ずつ個別性を削ぎ落として抽象化すること。各段は一つ前の段で検証する。
- ドッグフーディング: スキルをそのスキル自身に当てて改善すること。Create Skill で作ったスキルとフィードバックを Create Skill の事例にする。
- 参照先: スキルの手順が読む同梱ファイル。
- テンプレート: 採用する例から個別性を削ぎ落として得られる成果物の型。見出し・空欄・記入上の注意を示し、避ける例から避ける形と適用条件を注意に取り込む。その型からルールを発見できる。
- 原則: 成果物が望ましい状態にあるために従うことと避けることを、具体的に述べたもの。再利用の見込みがあるものを事例に蓄積する。
- 判断: ある場面で、ある形を採用する、または採用しないと決めたこと。
- 採用する例: 原則に従う形を示す具体例。個別性を削ぎ落とすことでテンプレートになる。
- 避ける例: 原則に反する形を示す具体例。テンプレートで避ける形と適用条件を明らかにする。
- 理由: 例から読み取れる動作の説明ではなく、他の場面にも適用できる一般原則で採用・不採用を説明したもの。用語集に載せる概念の出どころ。
- 潜在能力: その人が発揮できるのに、まだ言葉になっていない能力。
- フィードバック: 人が個別の成果物へ返す指摘や修正。暗黙知が現れる場面。
- 暗黙知: 主観的で言語化しにくい知。直感や勘、考え方や行動の癖、信念を含む。
- 事例: 個別の場面で起きたことの記録。成果物とそれに返されたフィードバックからなり、原則と例を取り出す元になる。
- 保証: 成果物について確かに成り立たせたいこと。チェックリストを作る動機になる。
- チェックリスト: 保証したいことの手段として、ルールを基準に Yes／No で検証できる項目を集めたもの。ルールとは一対一に対応しない。
- 観点: 対象のどこに着目するか。着目した性質を比較できる尺度にすると判断軸になる。
- レビュー項目: 役割の行動原理を観点にして、成果物が望ましい状態にあるかを見てギャップを見出すための問いの集まり。
- 用語集: 各語がこの領域で何を意味するかを定めるもの。抽象的な考え方から具体的な手順や事例まで、共通の言葉で捉えられるようにする。
